# Cubs Bakery & Cakes
## Platform
Responsive web frontend demo for one Mysuru bakery.
## Stack
React, Vite, TypeScript, React Router, Recharts, Lucide. Browser persistence, no backend or authentication.
## Product truth
Use supplied menu names and prices in integer paise. Contact: 0821 424 6688, Gokulam Main Road, Mysuru 570002. Closing 23:30. Opening time, capacity, delivery and loyalty are explicit demo assumptions. Never invent cake weights, flavours or surcharges.
## Users and tasks
Customers order as guests, track simulated payments, and reserve tables. Owners manage shared records, availability, refunds, customer history and rules.
